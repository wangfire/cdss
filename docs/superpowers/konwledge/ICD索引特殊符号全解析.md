# ICD 索引表特殊符号全解析

> 全表 51268 行，`索引级别=0` 为主导词共 6832 个，1~6 级修饰词逐级下挂。以下 7 类符号决定"能不能命中、要不要跳转、是否联合编码"。

---

## 一、长破折号 `－`（行首缩进符）— 修饰词层级标记

**出现 42425 条**（本表最高频）。它**不是内容，而是层级指示器**：行首 `－` 的个数 = 该修饰词挂在第几级。

| 写法 | 索引级别 | 含义 |
|---|---|---|
| 无 `－` | 0 | 主导词（检索入口） |
| `－xxx` | 1 | 一级修饰词 |
| `－－xxx` | 2 | 二级修饰词 |

**真实案例**（完整父子链，靠"父节点"列串起）：

```
阿尔茨海默病或硬化                 G30.9        (级别0 主导词)
－引起痴呆                        G30.9† F00.9*  (级别1 修饰词)
－－早期发病(早老性)              G30.0† F00.0*  (级别2 修饰词)
```

**规则**：只有主导词命中后，才在 `级别≥1` 的子行里逐级找修饰词；修饰词命中则用修饰词行的码，否则回退上级。

---

## 二、圆括号 `()` — 有 3 种子用途（共 13446 条）

这是最容易误判的符号，本表里它其实承担了**三种完全不同的角色**，必须区分：

### ① 澄清性修饰词（纯消歧）— 8724 条
**含义**：括号只是把前面主导词的适用范围说清楚，**诊断里写不写这个词，都不影响编码**。
- `ABO溶血病(胎儿或新生儿)  P55.1` → 读作"此处专指胎儿/新生儿的 ABO 溶血病"，编码直接是 P55.1
- `Rh(因子)  ...` → "因子"是提示词，可有可无
- `X线(的)  ...` → 括号"的"纯粹是语法澄清

**规则**：匹配时**先剥离括号内容**，它不参与命中判定；但若病例人群/部位与括号明显不符（成人却只有"胎儿或新生儿"条目），说明主导词选错，需改查别的主导词。

### ② 括号内嵌"见/另见"交叉引用 — 2463 条
**含义**：括号里不是修饰词，而是一个**跳转指令**，等价于第三类的"见/另见"，只是写在括号里。
- `13三体综合征  Q91.7` → 也可改去主导词"三体性，13"下查
- `－肝(另见 脓肿，肝，阿米巴)  A06.4`

**规则**：括号内的跳转和后面的 `- 见`同效，命中本行即可，也可顺指针去目标主导词复核。

### ③ 括号内是形态学编码 — 1951 条（见第六类）
- `癌(M8010/3) - 另见 肿瘤，恶性`
- `APUD瘤(M8248/1) - 见 肿瘤，动态未定`

**规则**：括号里的 `M码/动态码`是肿瘤形态学码，本身不单独作为 ICD-10 主编码，真正的编码要靠箭头去"肿瘤…"主导词下找。

---

## 三、方括号 `[]` — 同义词 / 别名 / 缩写（1350 条）

**含义**：方括号内是主导词的**另一个名字或英文缩写**，只帮你"认得出、找得到"，**同样不参与编码判定**。
- `SARS[严重急性呼吸道综合征]  U04.9` → 看到任一个都能定位
- `H病[哈特纳普病]  E72.0`
- `CREST综合征[肢端硬皮综合征]  M34.1`
- `21三体综合征[唐氏综合征]  Q90.9`

**规则**：与圆括号①一样，匹配前先剥离；它是主导词的"外号"，命中靠主名，不靠方括号里的词。

---

## 四、`- 见`（see）— 单纯跳转指针（3078 条）

**含义**：**这个条目本身不编码，让你改去另一个主导词查**。它是索引里的"路标"，本行通常无独立编码。
- 本表 3078 条 `- 见` 中，**2599 条自身无编码**（纯跳转），479 条虽带原始 M 码但仍指向他处。
- `阿米巴 - 见 阿米巴病` → "阿米巴"下不编码，去查主导词"阿米巴病"
- `APUD瘤(M8248/1) - 见 肿瘤，动态未定` → 去"肿瘤，动态未定"下找真正编码
- `－－伴有脓肿 - 见 脓肿，阿米巴` → 修饰词级别的跳转

**规则**：命中 `- 见` = 当前主导词不是编码所在地，**必须顺着箭头跳到指定主导词重新走一遍查找逻辑**，本行编码不可直接采用。

---

## 五、`- 另见`（see also）— 附加/补充检索指针（2823 条）

与"见"的关键区别：**"见"是完全改道；"另见"是当前行往往仍能编，只是提示"还有一个相关主导词也值得查"**（用于多主导词、合并编码或补充信息）。
- 本表 2823 条 `另见` 中，**2507 条本身带有效编码**（说明本行可编），仅 316 条纯跳转。
- `HIV - 另见 人(类)，免疫缺陷病毒[HIV]病` → HIV 相关编码在"…HIV病"主导词下完整展开
- `癌(M8010/3) - 另见 肿瘤，恶性` → 提示恶性肿瘤去"肿瘤，恶性"下按部位编码

**规则**：先按本行判定能否编码；若"另见"指向的主导词能提供更具体的部位/病因码（尤其肿瘤按部位编码的情形），优先去目标主导词取码。

> **"见" vs "另见" 一句话记忆**：`见`=必须改道（本行作废）；`另见`=本行可留，但目标处往往有更精确的码，需去核对。

---

## 六、`†` 剑号 / `*` 星号 — 强制联合编码（成对，2609 条）

**含义**：一个诊断需要**两个码**——`†`（剑号）记**病因**，`*`（星号）记**临床表现/部位**，二者必须同时使用。
- `阿尔茨海默病或硬化` 下：`－引起痴呆  G30.9† F00.9*` → 病因 G30.9† + 痴呆表现 F00.9*
- `Ⅱ型糖原贮积病  E74.0† I43.1*`
- `阿·罗[阿盖尔·罗伯逊]…(梅毒性)  A52.1† H58.0*`

**规则**：凡编码里出现 `†…*` 配对，**推荐结果必须同时给出两个码**，`†`在前（病因）、`*`在后（表现），不可只取其一。

---

## 七、`NEC` / `未特指` — 编码精确度的兜底标记（4517 条）

**含义**：都不是符号内容，而是编码"精确度"信号，决定该码是否只能作为兜底。
- `NEC`（其他特指）：病例有明确限定但无更细子目时的"特指其他"码，如 `－特指的 NEC  G30.8`、`－特指部位 NEC  A06.8`
- `未特指 / NOS`：诊断信息不全时落在主导词本身的默认码（如 `阿尔茨海默病或硬化  G30.9`）

**规则**：能找到更具体修饰词码时**优先用具体码**；修饰词都命不中、或修饰词行本身无独立编码时，才回退到 `NEC`/主导词的未特指码。

---

# 查找逻辑总口诀（把 7 类符号串起来）

1. **认主导词**：先忽略 `[]`（别名）和 `()`①（澄清词），确认主导词命中；
2. **看跳转**：本行有 `- 见` 必须改道重查；有 `- 另见` 或 `()`②内嵌另见，去目标主导词核对更精确码；
3. **逐级下钻**：按 `－` 的个数逐级匹配真正的修饰词，命中即用该子行码；
4. **辨形态码**：`()`③里的 `M…/动态码` 不单独作主编码，去肿瘤类主导词按部位编码；
5. **判精确度**：命中不了具体修饰词再落 `NEC`/未特指码；
6. **配剑星号**：凡 `†…*` 一律成对联合编码输出。
