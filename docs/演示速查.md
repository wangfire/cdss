## 三、建议演示动线

### 动线 1 · 编码录入（即时出码，最快、最亮眼）⭐ 推荐先演这个

1. 左侧菜单 → **编码录入**
2. 输入「**中心细胞性淋巴瘤**」→ 点解析
3. 展示：主导词拆分（淋巴瘤(恶性) / 细胞(性) / 瘤）→ 修饰词链路 → 有效编码推荐
4. 右上角徽标会显示本次生效的**标题通道开关**（诊断直达 / 手术直达 / 同族反查）
5. 可切换「诊断 / 手术」，输入「**阑尾切除术**」再演一次（走 CM3 手术索引链路）

**实测结果**（已验证）：

```

  C83.809  恶性淋巴瘤,中心母细胞性,弥漫性
  C83.806  恶性淋巴瘤,中心母细胞-中心细胞性,弥漫性
  C83.800  其他非滤泡性淋巴瘤
  C83.803  淋巴样肉芽肿病
```

### 动线 2 · 病例录入 → 流水线 → 审核（展示全链路 + 可追溯）

1. 左侧菜单 → **病例录入**
2. 填写：患者姓名、住院号、入院/出院日期
3. 入院诊断填「社区获得性肺炎」，出院诊断填「中心细胞性淋巴瘤」「高血压」，手术填「阑尾切除术」
4. 点提交 → 页面自动轮询任务状态（约 15~30 秒，LLM 校验会参与）
5. 完成后点 **查看工作台** → 审核工作台里能看到：
   - 任务列表与状态
   - 推荐明细（按类型分组：入院诊断 / 出院诊断 / 手术）
   - **证据链**（可展开看命中的文书片段）
   - 审核按钮：接受 / 修改 / 驳回
6. 点「接受」→ 最终编码落库

## 四、演示时可能被问到的问题（附标准答法）

### Q：推荐结果准不准？有多少是 AI 判的？

- 推荐**全部**来自 ICD-10 / ICD-9-CM-3 官方字典展开（`medical_code` 表，51,050 条），不是模型编的。
- 模型（本地 qwen2.5:3b）只做**一致性校验**：判断"这条候选有没有证据支持"，不产生编码。
- 每条推荐都能点开**证据链**，看到命中的原文片段。
- 当前口径：诊断编码级 Top1 约 27.5%、类目级约 43.8%（万条真值台账，口径未冻结前属内部参考值）。

### Q：数据在哪儿？会不会出院？

- 全部**本地**：SQL Server（LocalDB）+ 本地 Ollama 模型，不出内网。
- 字典来自 ICD-10 / ICD-9-CM-3 三库合并（国临/医保/国标）。

### Q：为什么工作台某些通道显示"降级"？

打开**运行记录**抽屉能看到每个阶段的状态。当前环境：

| 阶段 | 状态 | 说明 |
|---|---|---|
| BM25_RETRIEVAL | DEGRADED | 演示环境未启 Elasticsearch，自动降级到索引链路 |
| 其余 14 阶段 | SUCCESS | 含 SCORE 阶段（LLM 一致性校验实际执行） |

生产环境接上 ES 后该阶段自动转 SUCCESS。

### Q：安全吗？谁能改知识库？

- RBAC 33 个权限码 + 5 个角色模板；审核、导入、启停都是按钮级权限。
- 登录 5 次失败自动锁定 15 分钟；登录接口有 IP 限流。
- 关键操作写审计日志（索引启停、登录失败/锁定）。
- 生产环境 JWT 密钥强制替换，占位密钥启动即拒。

## 五、当前演示环境的已知限制（如实告知）

| # | 限制 | 影响 |
|---|---|---|
| 1 | 未启用 Elasticsearch / RabbitMQ | BM25 通道显示降级；不影响推荐结果（走索引链路） |
| 2 | 演示数据是**新建**的 | 之前 LocalDB 的 MDF 文件丢失，数据库已重建并重新灌入全量知识库（字典 51050 / ICD 索引 51268 / CM3 19671 / 肿瘤 1547 / 规则 2178 / 同义词 6134），但**历史任务与审核记录是新的** |
| 3 | 精度数字尚未冻结验收口径 | 对外报数时建议用"约"并注明口径，或暂不主动报具体百分比 |
| 4 | 前端为 dev server | 首次打开页面会编译，稍等几秒 |

## 六、演示期间出问题怎么办

```powershell
# 查看后端日志
Get-Content $env:TEMP\api_demo.log -Encoding UTF8 -Tail 50

# 查看前端日志
Get-Content $env:TEMP\fe_demo.log -Encoding UTF8 -Tail 30

# 重启后端
Get-Process dotnet | Where-Object { $_.Id -eq 41404 } | Stop-Process -Force
cd D:\CDSS智能编码系统\src\HospitalAi.Api
$env:ASPNETCORE_ENVIRONMENT='Development'
$env:ASPNETCORE_URLS='http://127.0.0.1:5080'
$env:ModelGateway__BaseUrl='http://127.0.0.1:11434'
$env:ModelGateway__ModelMode='OpenAiCompatible'   # 注意：枚举名，不是 openai_compatible
$env:ModelGateway__TimeoutSeconds='180'
$env:Elasticsearch__Enabled='false'
$env:RabbitMq__Enabled='false'
$env:HealthChecks__Elasticsearch__Enabled='false'
$env:HealthChecks__RabbitMq__Enabled='false'
Start-Process 'C:\Program Files\dotnet\dotnet.exe' `
  -ArgumentList 'bin\Debug\net10.0\HospitalAi.Api.dll' `
  -WorkingDirectory 'D:\CDSS智能编码系统\src\HospitalAi.Api' -NoNewWindow `
  -RedirectStandardOutput "$env:TEMP\api_demo.log" -RedirectStandardError "$env:TEMP\api_demo.log.err"

# 重启前端
cd D:\CDSS智能编码系统\web-ui
pnpm --filter @tabtab/admin dev
```

> ⚠️ **后端必须从 `src\HospitalAi.Api` 目录启动** —— 否则读不到 `appsettings.Development.json`（配置与工作目录相关）。
