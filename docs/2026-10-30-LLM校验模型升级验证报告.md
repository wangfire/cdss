## 一、验证方法

- 场景：与生产流水线逐候选调用完全同构（诊断原文 + 候选码/标题 + 带编号证据原文 ≤3 条 + 事实线索 → 4 字段 JSON，`format=json` + Schema 注入提示，`num_predict=160`、`temperature=0`）
- 语料：本地验证库 6 条真实风格 FRONT_PAGE 诊断（急性阑尾炎 / 2型糖尿病 / 原发性高血压 / 胆囊结石伴慢性胆囊炎 / 腰椎间盘突出症 / 社区获得性肺炎），每条 rank1 推荐 + 可匹配证据原文
- 判据：`cited_evidence` 非空且编号在证据范围内 = 证据引用维可得分（0.5B 时代的死穴）
- 工具：`scripts/validate_llm_model.py`（Ollama `/api/chat`，与网关同参数形状）；三档模型同一语料对比

## 二、三档实测对比

| 指标 | 0.5b（现状） | 1.5b | **3b（已切换）** |
|---|---|---|---|
| JSON 可解析 | 6/6 | 4/6（2 次把 Schema 原文当输出） | **6/6** |
| Schema 校验通过 | 6/6 | 4/6 | **6/6** |
| 回显码正确 | 6/6 | 4/4 | **6/6** |
| **cited_evidence 非空** | **0/6（恒空）** | 3/4 | **6/6** |
| 引用编号在范围内 | 0/6 | 3/3 | **6/6** |
| 延迟（热态 p50） | ~0.19s | ~0.33s | **~0.41s** |
| 内存占用（Q4_K_M） | ~0.4GB | ~1.0GB | ~1.9GB |

**关键结论**：
1. 0.5B 的 `cited_evidence` **恒为空数组**（与 10-09 报告的归因完全一致）——证据引用维（判据要求 cited 非空且证据原文支持标题）在 0.5B 上结构性拿 0 分；
2. 1.5B 出现**把 Schema 提示当输出内容**的失败模式（2/6），且偶发空引用——不可靠；
3. **3B 六项全绿**：引用编号选取稳定、回显码精确、Schema 零失败；
4. 延迟：3B 热态单候选 **0.41s**（0.5B 的 2 倍，但绝对值极小）；冷启动首请求 55s（模型加载，`OLLAMA_KEEP_ALIVE` 默认 5 分钟内复用为热态）。万条跑批 ≈3 万次调用，按 0.4s/次 + 并发 6 折算约 35 分钟，完全可接受。

## 三、在线端到端验证

- `POST /api/v1/coding/diagnosis-inputs/{id}/recommend`（真实 API + 3B 网关）：HTTP 200，Top1 `K35.900 急性阑尾炎`，终分 0.90，无降级标记；
- 登录链路（JWT + 33 项权限）正常；安全回归 **14/14 绿**（含锁定 423 / 限流 429 / 审计断言，本次容器库可用连 DB 集成测试也一并真实跑过）。

## 四、同步修复：EF 迁移精度不一致（阻塞项）

切换验证过程中发现并修复了一个**存量隐患**（提交 5c0877b 一并入库）：
- `HospitalAiDbContext` 中 `app_user.locked_until / lockout_at` 未显式指定列类型，EF 对可空 `DateTimeOffset?` 推断为 `datetimeoffset`（无精度），与迁移/快照的 `datetimeoffset(7)` 不一致；
- 后果：`Database:AutoMigrate=true` 时 `PendingModelChangesWarning` 直接抛异常，**新环境无法从空库自动建库**；
- 修复：DbContext 两列补 `.HasColumnType("datetimeoffset(7)")`；`dotnet ef migrations has-pending-model-changes` 现返回 "No changes"。

## 五、运维注意

1. **模型驻留**：生产机建议设置 `OLLAMA_KEEP_ALIVE=30m`（或流水线侧保活），避免每 5 分钟冷启动 55s；
2. **同机线程预算**：3B CPU 推理线程数默认跟随核数，与 ONNX 向量/Rerank 同机时沿用"核数预算"纪律（`EmbeddingOptions.IntraOpThreads=4` 已内置）；
3. **精度口径**：本轮只验证了链路能力（引用合法率/回显/延迟）。**万条 L0/L1 口径的 LLM-on 重跑与 Top1 排序税复测**（上轮 −79）是下一个动作；在新数字出来前，对外精度口径仍按 LLM-off 公布；
4. **回滚**：配置回滚只需把 `model.small` 映射改回 `qwen2.5:0.5b-instruct`（Ollama 未删旧模型）。
