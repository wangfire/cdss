## 2. 安全策略（阻塞）

| # | 检查项 | 默认值 | 评审口径 |
|---|---|---|---|
| 2.1 | **`Security:RateLimit:LoginPermitLimit`**（登录限流阈值） | 60 次/60 秒 | **NAT 密集的内网必须放宽**：按"医院同时段最大并发登录人数"估算，建议 `并发登录峰值 × 1.5~2`；公网入口或暴露面大时收紧到 20~30。窗口 `LoginWindowSeconds` 同步评审 |
| 2.2 | `Security:Lockout:MaxFailedAccessAttempts` / `LockoutDurationMinutes` | 5 次 / 15 分钟 | 与院方安全策略对齐；**不关闭**（≤0 等于放弃暴力破解防线） |
| 2.3 | `Security:AllowHeaderIdentity` | `false` | **生产必须 false**（头占位认证 = 身份可伪造） |
| 2.4 | Swagger | 非 Production 自动关闭 | 确认生产 `/swagger` 返回 404 |
| 2.5 | CORS `admin` 策略 | 生产仅允许 `localhost:3001` | 内网域名部署时改为实际前端源 |
| 2.6 | HTTPS / 反向代理 | 前置 Nginx/IIS | 证书有效；`X-Forwarded-For` 正确透传（登录限流按真实客户端 IP 分区，未透传 = 全院内网共享一个限流桶） |

## 6. 冒烟验收（上线前最后一步）

```powershell
# 1. 冒烟脚本全绿
pwsh -File tests/smoke/run.ps1 -SkipBuild

# 2. 错误登录 5 次 → 第 5 次 423（锁定生效）
# 3. 同 IP 60+ 次/分钟 → 429（限流生效）
# 4. 错误密码登录一次 → 400 validation_error（不泄露用户枚举信息）
# 5. 正确凭据登录 → 200 + JWT；/api/v1/auth/me 携带 Bearer 可用
# 6. 匿名访问任意业务端点 → 401
```

## 7. 回滚预案

| 场景 | 动作 |
|---|---|
| 迁移失败 | 停机回滚到上一镜像；`app_user` 新列（锁定三列）与 `app_role_permission` 种子行**不影响旧代码运行**，无需回滚 DDL |
| 限流误伤院内用户 | `Security:RateLimit:LoginPermitLimit` 调大或 `=0` 关闭（热更新需重启）；登录锁定独立不受影响 |
| 锁定风暴（大量用户被锁） | 管理员批量解锁（账户页逐个）或临时 `MaxFailedAccessAttempts=0` 关闭锁定策略后重启；事后恢复 |
